# 个人候选过滤与拼音纠错

这些配置按个人使用习惯维护，安装时按需选择。默认的专业词库模板不会启用过滤。

## 两种可选方案

| 方案 | 模板 | 使用的数据 |
|---|---|---|
| 只增加拼音纠错 | [拼音纠错模板](../examples/wanxiang.corrections.custom.yaml) | `typing_corrections.tsv` |
| 拼音纠错 + 严格过滤 | [个人过滤模板](../examples/wanxiang.personal-filter.custom.yaml) | `blocked_words.txt`、`blocked_word_rules.tsv` |

两种方案都需要把 [`../lua/personal_word_filter.lua`](../lua/personal_word_filter.lua) 放入用户目录的 `lua/`，把对应数据文件放入 `custom/`，再将模板合并到用户目录的 `wanxiang.custom.yaml`。模板都包含专业词库挂载，因此也要复制根目录的专业词库。

过滤器应追加到 `engine/filters` 末尾。已有 `engine/filters/+` 时，将 `lua_filter@*personal_word_filter` 合并进去一次。短语示例需要合并到用户目录的 `custom_phrase.txt`。最后重新部署。

## 拼音纠错

万象字表里“兺”的编码是 `būn`，可能让 `nengbun` 被解释为“能兺”。模板在拼写转换开头插入 `erase/^būn$/`，让输入可以按 `neng + bu + n` 解析。`contains<Tab>兺` 规则同时排除含这个字的候选，覆盖已经学习的词和自动组句。

[`../custom_phrase.example.txt`](../custom_phrase.example.txt) 提供 6 条输入编码：

| 输入 | 固定短语 |
|---|---|
| `nengb`、`neng'b`、`nengbu`、`neng'bu` | 能不 |
| `nengbun` | 能不能 |
| `ninengbun` | 你能不能 |

2026-11-10 在小狼毫 0.17.4 / librime 1.13.1 的万象标准版全拼中验证了 13 组输入，包含上述编码、单引号分词、`wonengbun`、完整拼音及专业词回归。

## 严格过滤的范围

严格过滤目前包含 460 个完整候选和 582 条片段／英文整词规则，覆盖成人内容、性行为、性暗示、相关器官与用品等。范围包含部分性教育、性健康、性取向等中性表达，请先查看名单并按个人需求调整。

规则作用于最终候选，包含固定词库、用户词、长词补全及自动组句。繁体候选在判断时转换为简体，显示文本本身不因此改变。

这是一套词条与规则过滤器。新的隐语、谐音和依赖上下文的双关可能漏过；多义词也可能误匹配。

## 维护格式

`blocked_words.txt` 每行一个完整候选，适合“双飞”“后入”等多义短词。完整候选匹配优先于片段规则。

TSV 文件各列之间使用真实 Tab：

```text
contains	乳交	乳交酯|水乳交融
contains	射精	发射精度|反射精度|散射精度
word	sex
```

- `contains`：拦截包含该片段的候选。可在第三列添加正常用法例外，用 `|` 分隔。
- `word`：不区分大小写，按英文字母、数字和下划线的边界匹配整词；`sex` 不会匹配 `sexagesimal`。
- 例外只豁免本条规则中的相应出现位置。同一候选另有受屏蔽内容时仍会被拦截。
- 空行及 `#` 开头的注释会被忽略。

修改时同时检查普通用法，例如“线性相关”“非线性器件”“发射精度”“公益性服务”“水乳交融”。新规则不要只用单个“性”“色”“裸”等字。

在仓库根目录运行：

```bash
python tools/check_personal_files.py
```

这个工具检查数据格式、重复规则与例外格式，不模拟 Rime。修改后将对应文件同步到用户文件夹，重新部署并验证候选。

## 已有验证记录

初版严格过滤包含 581 条规则时，在本机 librime 中验证了 1,006 个屏蔽样例和 76 个正常样例，均符合预期；当时 684 条专业词通过误匹配检查。随后增加“兺”纠错规则，共 582 条。

这些记录针对当时的配置与运行环境。仓库中的 GitHub Actions 执行格式校验，实际输入行为仍需要本机部署确认。
