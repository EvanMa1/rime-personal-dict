## 增补词条

1. 在词库对应分类下添加词语，分类行形如 `# [estimation] 参数估计与贝叶斯推断`。
2. 每行采用 `词条<Tab>带声调拼音<Tab>词频` 三列，使用真实 Tab；音节之间使用一个半角空格。
3. 保存为 UTF-8，声调字母采用 NFC 形式，每个汉字对应一个音节。目前只收录中文词语。
4. 确认专业含义及多音字后，更新词库头部版本为 `YYYY.MM.DD.N`，并更新根目录的维护记录。
5. 执行校验，将词库同步到 Rime 用户文件夹，重新部署并验证输入。

以下示例已在词库中，供参考格式：

```text
空时自适应处理	kōng shí zì shì yìng chǔ lǐ	200
最大似然估计	zuì dà sì rán gū jì	200
泊松分布	pō sōng fēn bù	200
```

词频约定：核心高频术语 `200`，一般专业词 `100`，较少使用的词可用 `80`。候选排序还受语言模型和使用记录影响。

## 专业读音

- 相控阵、相位：`xiàng`；相干：`xiāng`。
- 似然：`sì rán`；泊松：`pō sōng`；伽马：`gā mǎ`。
- 协方差：`xié fāng chā`；卡方：`kǎ fāng`。
- 技术含义的“分量”：`fēn liàng`；主成分：`zhǔ chéng fèn`。
- 重采样：`chóng cǎi yàng`；重尾分布：`zhòng wěi fēn bù`。
- 距离徙动：`jù lí xǐ dòng`；共轭：`gòng è`。

校验工具对这些技术搭配另做检查。逐字读音校验使用万象字表，不等同于专业术语的完整审校。

## 校验与安装

在仓库根目录运行：

```bash
python tools/check_radar_dictionary.py
python tools/check_radar_dictionary.py --chars /path/to/rime/dicts/chars.dict.yaml
```

第一条命令校验结构与部分技术搭配；第二条额外逐字核对本机万象字表。字表路径也可以用 Windows 路径，包含空格时加引号。

词库通过以下补丁接入用户目录的 `wanxiang.custom.yaml`：

```yaml
patch:
  "translator/packs/+":
    - radar_statistics
```

合并时只保留一个顶层 `patch:`。词库与万象主词库共享带声调的音节表，输入时仍使用无声调拼音。详细安装步骤见 [仓库首页](../../README.md)。

重新部署后，应生成 `build/radar_statistics.table.bin`，并能在 `build/wanxiang.schema.yaml` 中找到对应的 `translator/packs` 项。日常修改源词库，生成文件由部署过程维护。
